# School Staff Shortages and the Wider Labor Market

A live dashboard that puts school staff vacancies in the context of the whole U.S. labor market, over time.

- **National labor-market data** (BLS JOLTS, CES and CPS, via the BLS Public Data API) refresh automatically twice a week through a GitHub Action.
- **National school vacancy estimates** (NCES School Pulse Panel, October 2022–2024) are re-checked by the same Action in case NCES publishes new waves.
- **State data** (Illinois, Virginia, Michigan, Pennsylvania, South Carolina, Iowa, Colorado, Nebraska) are curated by hand in `data/states.json` and updated about once a year.

It is a static site: plain HTML/CSS/JS, with no build step and no server, hosted free on GitHub Pages.

- **To publish it for the first time, follow [PUBLISHING.md](PUBLISHING.md)** (written for someone new to GitHub).
- **For where every number comes from**, see `provenance.html` (the "Data provenance" page on the live site).

## Files

| Path | What it is |
|---|---|
| `index.html`, `assets/app.js`, `assets/style.css` | The dashboard. Every chart and every sentence that quotes a number is generated from the data files. |
| `provenance.html`, `assets/provenance.js` | Data provenance page: sources, retrieval, transformations, verification, known issues, corrections. Tables are rendered from the same data files. |
| `data/national.json`, `data/national_monthly.csv` | Generated by `scripts/fetch_national.py`. Don't edit by hand. |
| `data/spp.json` | Generated by `scripts/fetch_spp.py` (NCES School Pulse Panel). Don't edit by hand. |
| `data/staffing.json` | Generated by `scripts/fetch_staffing.py` (NCES Digest Table 213.10: public school staff FTE and enrollment, fall 2000 on). Don't edit by hand. |
| `data/states.json` | Hand-curated state data: every point with its basis and source note, each state's definition of "vacancy", comparability group, and verification record. |
| `data/state_inventory.json` | Hand-curated 50-state inventory: what each state publishes and why it is or isn't on the dashboard. |
| `scripts/fetch_national.py` | Pulls all national series from the BLS Public Data API. Python standard library only. A free BLS key (secret `BLS_API_KEY`) is strongly recommended; see PUBLISHING.md step 9. |
| `scripts/fetch_spp.py` | Pulls the NCES School Pulse Panel staff-vacancy workbook. Needs `openpyxl`. |
| `scripts/fetch_staffing.py` | Pulls the newest edition of NCES Digest Table 213.10 (staff by type and pupils per staff member). Needs `openpyxl`. |
| `.github/workflows/update-data.yml` | Runs the three fetch scripts on Tuesdays and Fridays and commits only when a value changes. |
| `PUBLISHING.md` | Step-by-step guide to putting the site online and keeping it updated. |

## Preview locally

```bash
python -m http.server 8765
```

Then open http://localhost:8765. Opening `index.html` directly from disk won't work, because browsers block `fetch()` of local files.

To refresh the data by hand:

```bash
python scripts/fetch_national.py
```


## Keeping it current

**National data:** nothing to do. JOLTS is released early each month, and the Action picks it up within a few days. If a fetch fails (an API outage, say), the script exits without touching the data, so the site keeps the last good pull, and GitHub emails you about the failed run. JOLTS revises past months, so the script re-pulls the full history every time.

**State data:** when a state publishes a new figure, edit `data/states.json`:

- Add a point like `{"sy": "2026-27", "unfilled": 1234, "filled": 56789, "note": "Source and anything unusual."}`.
- `sy` is the school year the figure *describes*. If the agency labels it differently (Iowa does), also record `"agency_label"`.
- Give `rate_published` when the agency publishes the rate itself. Give `filled` (or `total`) when only components are published, and the page will compute the rate and label it "computed". Use `"basis": "Third-party calculation"` for figures not published by the agency. Leave out what isn't published, and say why in `note`. The page never estimates.
- If a state changes what it counts, update its `measure` block, the definition the page shows in "What counts as a vacancy".
- Update the state's `verification` text, and `"updated"` and `"verified"` at the top of the file.
- If something was corrected, add a row to the corrections log in `provenance.html`.

Where to look each year:

| State | Typical release | Source |
|---|---|---|
| Illinois | Winter/spring | ISBE Unfilled Positions data; IWERC Educator Shortage report |
| Virginia | December (Board meeting) | VDOE Positions & Exits Collection; Board of Education presentation and news release |
| Pennsylvania | Late fall/winter | PDE Professional Staff Vacancy workbook (Q1, October 1) for vacancies and the Professional Staff Summary (State_FT+PT, CT column) for classroom teachers, both on the professional and support personnel page. Rate is computed. |
| Michigan | January | Michigan Teacher Shortage Study (EPIC/MSU), vacancy section: the statewide FTE-weighted rate for the prior fall |
| Iowa | January | Iowa DOE press release and district spreadsheet on the Teacher Shortage Areas page. **Check the posting window** in the spreadsheet note: the figure covers the *previous* 12 months, so plot it one school year earlier than the press-release label. |
| South Carolina | Winter/spring | CERRA Educator Supply & Demand data tables (Table 5) |
| Colorado | Spring/summer | CDE Educator Shortage Survey results page and workbook |
| Nebraska | January | NDE Teacher Vacancy Survey summary |

**50-state inventory (once a year, ideally late summer):** re-check every state in `data/state_inventory.json` using the protocol recorded in that file. In short, search each state agency's own site for vacancy data, read anything found, classify it, and record the evidence links. Then compare with the Learning Policy Institute's annual scan (published each July) as a cross-check, never as the source. States to watch:
- **Ohio** and **Texas:** new laws require vacancy collections starting in 2026-27; Ohio must publish its results.
- **Alaska:** checked by hand in October 2026 and left off the dashboard, because it counts positions held by someone without a valid Alaska certificate as vacant. Re-check if the department starts reporting truly empty positions separately.
- **Arizona** and **Tennessee:** their reports block automated download; save copies to the Drive `sources` folder.

The October JOLTS benchmarks on the state panels come from the automated national pull, so a new school year's benchmark appears once BLS publishes October data (early December).

**Adding a state:** add an object to `states` in `data/states.json`, with the same shape as the others, including `tier` (`snapshot` or `different`) and a `measure` block. The page draws a panel for it automatically. Move the state from `candidate` to `included` in `data/state_inventory.json`.
